# scenarios/ — what to run

One folder per demo scenario you present. Required: `scenario.yaml` (which apps run on which node) and `README.md` (the story: value proven, story, demo beats, setup, acceptance tests, talking points). Optional: `apps/` for apps only this scenario needs.

Create with `./protorig new scenario <name>`. The README is written first; it is the spec the apps are built from.

See [docs/WORKFLOW.md](../docs/WORKFLOW.md#scenarios--what-to-run).
